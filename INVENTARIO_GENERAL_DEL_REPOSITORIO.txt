SECCIÓN 1: PROGRAMAS PRINCIPALES Y SCRIPTS PYTHON EN LA RAÍZ
================================================================================

[01] train.py
     - Tipo: Script Python principal (Entrenamiento general).
     - Función: Punto de entrada para el entrenamiento de redes neuronales de pixel art.
       Gestiona el bucle de entrenamiento, selección de fases (Fase 1: 16x4 con Conny/Dana,
       Fase 2: 8x12 con Alex/Amaro), cálculo de funciones de pérdida (L1 + Perceptual +
       Adversarial + Alpha/Color) y guardado automático de checkpoints periódicos.

[02] train_dos_fases_1500.py
     - Tipo: Script Python de pipeline automatizado completo.
     - Función: Ejecuta una rutina de entrenamiento de 2 fases encadenadas (hasta 1500-2000 épocas).
       Fase 1: Pulido de alta definición en rejilla 16x4 (64 frames) focalizado en detalles de 1px.
       Fase 2: Transfer learning hacia rejilla canónica 8x12 (96 animaciones completas).
       Incluye control de parada temprana, prevención de colapso y validación continua.

[03] pulir_fase1.py
     - Tipo: Script Python de afinamiento y super-resolución.
     - Función: Toma el checkpoint base de la Fase 1 (alrededor de la época 500-700) y aplica
       un ajuste fino de hiperparámetros (tasa de aprendizaje reducida, peso adversarial
       controlado de 0.15) para forzar bordes duros de 1px, limpieza de ruido y definición
       anatómica sin distorsionar las proporciones maestras.

[04] generate_character_sheet.py
     - Tipo: Script Python principal de inferencia (Generador de Spritesheets).
     - Función: Recibe como entrada una imagen frontal o spritesheet base de un nuevo
       personaje y genera automáticamente la hoja completa de animaciones (16x4 o 8x12)
       utilizando el modelo neuronal entrenado (best_generator.pt) y el módulo de mejora.

[05] pipeline_hibrido_tori.py
     - Tipo: Script Python de síntesis híbrida.
     - Función: Diseñado para personajes complejos como Tori (vestimenta con capucha y silueta
       más ancha). Combina generación guiada con plantillas de pose, destilación de frames
       originales, re-escalado canónico y post-procesado morfológico de píxeles.

[06] fase3_revision_critica.py
     - Tipo: Script Python de elevación estética y revisión crítica.
     - Función: Implementa la 'Fase 3' del diseño: analiza pixel a pixel las hojas generadas,
       corrige asimetrías en ojos, empareja tonos de piel según la paleta del personaje,
       limpia píxeles flotantes (stray pixels) y genera vistas previas ampliadas con zoom 4x.

[07] finalize_generated_sheets.py
     - Tipo: Script Python de ensamble geométrico final.
     - Función: Toma las hojas generadas por la IA y las ajusta a la cuadrícula canónica
       estricta (724x2172 px o 1024x1536 px), asegurando que cada celda de sprite quede
       centrada con su punto de anclaje en el suelo sin cortes en los bordes de la celda.

[08] extract_individual_frames.py
     - Tipo: Script Python de segmentación de dataset.
     - Función: Procesa los spritesheets de Alex, Amaro, Conny, Dana y Tori, cortando cada
       animación en frames individuales etiquetados con su fila, columna, dirección y acción
       (caminar, idle, cocinar, pensar, caja, celebrar) hacia dataset_frames_individuales/.

[09] normalize_spritesheets.py
     - Tipo: Script Python de normalización geométrica general.
     - Función: Convierte spritesheets en bruto a la plantilla estándar canónica de 724x2172 píxeles,
       estandarizando espacios entre celdas, transparencias alfa y alineaciones de cabeza y pies.

[10] normalize_8x12_dynamic.py
     - Tipo: Script Python de normalización dinámica para rejilla 8x12.
     - Función: Detecta dinámicamente la caja delimitadora (bounding box) de cada sprite en celdas
       de 128x128 píxeles y lo ancla en el piso de la celda de forma consistente en toda la animación.

[11] normalize_8x12_cv2_mold.py
     - Tipo: Script Python de normalización asistida por visión artificial (OpenCV).
     - Función: Utiliza máscaras binarias y detección de contornos mediante OpenCV para encajar
       sprites en un molde predeterminado, corrigiendo deformaciones de escala.

[12] normalize_8x12_global.py
     - Tipo: Script Python de normalización con escala global uniforme.
     - Función: Aplica un único factor de escala global a todos los frames del personaje para
       garantizar que no haya variaciones involuntarias de estatura entre diferentes animaciones.

[13] normalize_8x12_local.py
     - Tipo: Script Python de ajuste local celda por celda.
     - Función: Ajusta el centrado horizontal y vertical de forma individual frame a frame,
       especialmente útil para frames de movimiento lateral con brazos extendidos.

[14] audit_frames_8x12.py
     - Tipo: Script Python de auditoría de frames.
     - Función: Inspecciona y genera un reporte en CSV/JSON con las dimensiones exactas,
       posiciones de centro de masa y niveles de transparencia de cada uno de los 96 frames.

[15] audit_quality_8x12.py
     - Tipo: Script Python de auditoría de calidad métrica.
     - Función: Evalúa la fidelidad del pixel art midiendo cantidad de colores únicos, presencia
       de píxeles semitransparentes indebidos (anti-aliasing borroso) y consistencia cromática.

[16] audit_problem_sheets.py
     - Tipo: Script Python de diagnóstico de sprites problemáticos.
     - Función: Genera paneles de auditoría visual lado a lado (Original vs Generado vs Diferencia)
       para las hojas y filas reportadas con fallos de anatomía o ropa.

[17] repair_problem_sheets.py
     - Tipo: Script Python de reparación de hojas con anomalías.
     - Función: Aplica parches correctivos sobre spritesheets dañados (recuperando frames
       deformados desde las fuentes maestras originales) sin alterar el resto de la hoja.

[18] sample_frames_8x12.py
     - Tipo: Script Python de muestreo y validación visual.
     - Función: Extrae un conjunto representativo de celdas clave (frente, perfil, espalda,
       acción de trabajo) para verificación rápida por parte del diseñador humano.

[19] check_dims.py
     - Tipo: Script Python de diagnóstico de dimensiones.
     - Función: Comprueba las resoluciones exactas en píxeles de plantillas, marcos y hojas maestras,
       verificando que cumplan con los múltiplos requeridos (ej. 1024x1536, 724x2172, 341x1024).

[20] check_syntax.py
     - Tipo: Script Python de prueba de sintaxis.
     - Función: Compila internamente con py_compile los módulos centrales para garantizar que
       no existan errores de sintaxis antes de lanzar entrenamientos largos en segundo plano.

[21] create_blank_canonical_grid.py
     - Tipo: Script Python generador de lienzos base.
     - Función: Genera plantillas y cuadrículas transparentes o con guías visuales (marcos y líneas)
       en blanco con la geometría canónica exacta requerida por el pipeline.

[22] test_pipeline.py
     - Tipo: Script Python de integración y testeo rápido.
     - Función: Carga el modelo actual, ejecuta una pasada completa de prueba (inferencia +
       enhancer + guardado de imagen) y reporta si todos los módulos funcionan armónicamente.

[23] monitor_server.py
     - Tipo: Script Python servidor HTTP local.
     - Función: Servidor ligero basado en http.server que expone en http://localhost:8787
       el panel de control visual en tiempo real (monitor.html) con métricas y previews.

[01] run_train.bat
     - Tipo: Menú interactivo en consola Windows.
     - Función: Ofrece opciones numeradas para:
       1) Entrenar Fase 1 (16x4 con Conny y Dana).
       2) Entrenar Fase 2 (8x12 con Alex y Amaro).
       3) Iniciar el servidor de monitoreo web.
       4) Salir.

[02] run_train_dos_fases_1500.bat
     - Tipo: Lanzador automatizado de pipeline completo.
     - Función: Ejecuta train_dos_fases_1500.py con 800 épocas para Fase 1, 1100 para Fase 2
       y batch size de 8, corriendo el pulido, la transferencia y la elevación final.

[03] run_train_fase1_16x4.bat
     - Tipo: Lanzador directo de Fase 1.
     - Función: Inicia directamente el entrenamiento de la base pequeña (16x4 / 64 frames)
       guardando resultados en checkpoints/base_generator_16x4.pt.

[04] run_train_fase2_8x12.bat
     - Tipo: Lanzador directo de Fase 2.
     - Función: Inicia la transferencia de conocimiento hacia la plantilla completa de 8x12
       (poses de cocina, pensar, servir, celebrar) guardando en checkpoints/best_generator.pt.

[05] run_train_infinite.bat
     - Tipo: Lanzador de entrenamiento continuo con auto-reanudación.
     - Función: Lanza en paralelo el servidor del monitor web e inicia el bucle de entrenamiento
       con batch size 16 hasta interrupción manual (Ctrl+C), guardando cada 10 épocas.

[06] run_pulir_fase1.bat
     - Tipo: Lanzador de optimización de detalles finos.
     - Función: Ejecuta pulir_fase1.py para reanudar el modelo de Fase 1 y aplicar los filtros
       anti-colapso y texturizado nítido de 1px.

[07] run_generate.bat
     - Tipo: Lanzador interactivo de generación para usuarios.
     - Función: Permite ingresar el nombre o ruta de un personaje para generar su spritesheet
       completo de manera sencilla sin comandos manuales.

[08] run_monitor.bat
     - Tipo: Lanzador de interfaz web.
     - Función: Configura la terminal con codificación UTF-8 (chcp 65001), abre el navegador
       en http://localhost:8787/monitor.html y arranca monitor_server.py.

[09] run_dims.bat
     - Tipo: Lanzador de comprobación de resoluciones.
     - Función: Ejecuta check_dims.py para verificar la compatibilidad de dimensiones de plantillas.

[10] run_check.bat
     - Tipo: Lanzador de comprobación rápida.
     - Función: Ejecuta comprobaciones generales de sanidad del entorno de Python.

SECCIÓN 3: MOTOR DE INTELIGENCIA ARTIFICIAL (pixel_ai_engine/)
================================================================================

[01] pixel_ai_engine/__init__.py
     - Tipo: Módulo de inicialización del paquete.
     - Función: Declara la carpeta como paquete de Python e importa los componentes clave.

[02] pixel_ai_engine/config.py
     - Tipo: Módulo de configuración global del motor.
     - Función: Centraliza rutas de carpetas, resoluciones de trabajo (16x4, 8x12, 128x128 px
       por celda), hiperparámetros de entrenamiento (learning rate, betas de Adam, pesos de pérdidas)
       y paletas cromáticas canónicas de cada personaje.

[03] pixel_ai_engine/models.py
     - Tipo: Arquitecturas de redes neuronales y funciones de pérdida personalizadas.
     - Función: Implementa:
       * Generador U-Net con conexiones residuales y normalización adaptativa.
       * Discriminador PatchGAN multiescala de alta resolución.
       * Pérdidas compuestas: Pérdida L1, Pérdida Perceptual (VGG), Pérdida de Color y
         Pérdida de Borde Duro (especial para preservar estética de pixel art).

[04] pixel_ai_engine/dataset.py
     - Tipo: Cargador de datos y preprocesamiento de imágenes.
     - Función: Implementa clases PyTorch Dataset/DataLoader para cargar spritesheets y frames,
       aplicar aumentos geométricos compatibles con pixel art (sin interpolaciones bilineales)
       y gestionar la caché de tensores en memoria.

[05] pixel_ai_engine/train.py
     - Tipo: Motor interno de entrenamiento del paquete.
     - Función: Contiene la lógica profunda del bucle de entrenamiento, retropropagación,
       actualización del optimizador, registro de estadísticas en training_status.json y
       generación de vistas previas en training_samples/.

[06] pixel_ai_engine/enhancer.py
     - Tipo: Módulo quirúrgico de post-procesamiento y mejora de Pixel Art.
     - Función: Realiza operaciones morfológicas discretas sobre las imágenes generadas:
       cuantización de color a la paleta maestra, binarización de canal alfa (sin transparencias
       parciales), remoción de píxeles huérfanos aislados y refuerzo de contornos oscuros.

[07] pixel_ai_engine/phase3_critical_enhancer.py
     - Tipo: Módulo avanzado de revisión crítica de tercera etapa.
     - Función: Aplica mejoras anatómicas refinadas: alineación perfecta de rasgos faciales
       (ojos simétricos de 2x2 o 1x2 px), detección y corrección de orejas, ajuste de accesorios
       (gorro de chef, delantal, botones) y armonización de volumen.

[08] pixel_ai_engine/quality_gate.py
     - Tipo: Puerta de control de calidad automática (Quality Gate).
     - Función: Evalúa métricas numéricas sobre los sprites generados (IoU de silueta, PSNR,
       SSIM contra la pose canónica y coherencia temporal entre frames contiguos). Si el sprite
       no supera el umbral de calidad del 85-90%, activa alertas o repite el refinamiento.

[09] pixel_ai_engine/generate_character_sheet.py
     - Tipo: Módulo interno de inferencia y ensamblado de spritesheet.
     - Función: Lógica de bajo nivel que toma una imagen de referencia, la proyecta a través
       de la red generativa celda a celda y ensambla la matriz completa de animación.
